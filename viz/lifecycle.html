上海 2024 年官方只发布全年龄的八大类总额：— 元 / 人 / 年。年龄形状分三段给出——0–17 岁是逐带逐类的篮子（吃、穿、用、学费、医疗各自给绝对额）；18–22 岁是独立构造的大学成本（学费 + 住宿 + 生活费）；23–85 岁是户均消费 × 成人份额调整 φ(a) × 退休缓坡 ρ(a)。八类的年龄梯度由 12 个 age knot 给定，最后用 IPF 把列和压回官方八类、行和压回 — 元，单格压缩上限 15%（实测最大 6.07%）。所以这张图回答的是「如果上海 2024 年的年龄结构与这三段显式假设一致，会是什么样」，而不是「统计局的抽样调查结果」。

0–2 岁的托育口径（v4 新增）

低档（三岁均值 3%）下 2→3 岁自己就到 +16.4%，超过我们 12% 的报警线——说明「0–2 岁没有两位数跳变」是入托率假设证出来的，不是数据证出来的。三档下 30–39 岁只差 0.06%（62,749.6 / 62,729.7 / 62,710.5）：入托率是局部参数，只动 0–3 段，和 glide 的全表平移不是一回事。

基准档的 2 岁入托率 11% 是区间上偏，不是点估计：这一档决定 2→3 岁台阶的高度，甚至决定谷落在 0 岁还是 2 岁。三档入托率下 2→3 岁分别是 +16.4% / +8.6% / +1.8%（三岁均值 3% / 5.5% / 8%）；再往下压，谷就退回 2 岁——「最便宜的一年」因此不是一个观测事实，而是这条假设的下游。见控制条里「入托率」那一行。

独立审计与重建（v1 → v2 → v3）

2026-11-07，本页被一份独立盲测（notes/independent/）推翻并整体重建。审计给出五条 P0，全部改掉；随后 v2→v3 又撤回了其中一条自己加出来的装饰：

  • 婴儿段是假的。v1 把育娲 0–2 岁总额四等分为食 / 住 / 医 / 其他，导致 0 岁医疗 12,066 元。v2 改为逐带篮子，0 岁医疗 1,300 元、占比 4.0%。
  • 30–49 岁被家庭分母摊薄。「家庭支出 ÷ 人数」把有孩年龄段压凹，成年峰被机械推到 59 岁。v2 引入 φ(a)（成人份额调整，45 岁 1.127），30–39 / 40–49 分别上移 31% / 23%，峰回到 46 岁。
  • 18 岁的断崖是口径拼接。v1 的 17 岁含家庭住房分摊、18 岁切成住校，落差 −25.1%。v2 两端同口径，实测 −7.8%。
  • 4 岁峰是幼儿园假设的产物。v1 用 12,000 元/年民办园，还叠了一个被抬高的婴儿段。v2 base 用公办 5,000，4 岁 38,660 元——在 86 个年龄里排第 83 位。
  • 60 岁那个「崖」是硬乘出来的。v2 为了让叙事上有一道断崖，加了 ρ(a)=1−0.10·smoothstep(59,60) 这个乘数，59→60 掉 3.5%。复核发现去掉它只剩 −0.49%——那个台阶完全是乘数造出来的，不是数据里的东西。v3 已删除，改成五年 glide（ρ 从 1.00 线性降到 0.90），单年只降 3.5%、五年累计 12.4%。这是本轮唯一一处叙事被判定为「装饰」并撤回的地方。

峰值落在 46 岁，是成年段年龄梯度的最大值所在，属参数设定而非实测发现；它可靠的地方是「不在育儿期、也不在退休后」这个位置，而不是 46 这个年份。同理，任何单年数字只代表模型，不代表某一年的真实支出。

仍然没解决的三件事（不藏）：

  • 22 → 23 岁那条缝是向上的（+14.0%）：22 岁还是「住校」口径，23 岁突然要租房。一半是真实的（毕业后自己付房租），一半是口径切换，但方向与幅度都无法用官方数据验证。这是 v3 里全图唯一向上的大跳。
  • 0 岁医疗 2,200 元（占 6.9%）仍比独立先验低约 27%：先验给的是含自费疫苗与儿保的 3,000–3,500。这一格与「医疗在 0 岁就该高」的直觉不符，是本表第二处标注。差额主要是自付与医保目录口径差，但没法证实。
  • 户均锚定偏 −1.54%：户均加权 125,584 元，对锚点 127,554 元。构造的 1 / 2 / 3 / 2 / 1.4 人家庭构成比七普偏小（一人户 11% vs 28%），这一项不是精度问题，是构造假设的问题。

三个最脆弱的假设

  1. 23–30 岁的居住金额（≈20,800 元/年）。这是 v1 留下、审计判为「与先验相符」的列；v3 把 23 岁总额压到 52,419 元后，居住占比落在 39.7%——仍高于先验 35% 的上限，但已不像 v2 那样刺眼。若上海年轻租客更依赖合租（15,000–18,000），23–29 段整条要下移 4,000–6,000。
  2. 3–5 岁的幼儿园口径（公办 5,000）。换成民办 12,000，3–5 段整体上移约 18%（38,899 → 45,899），但峰仍然在 46 岁——这一条本身也是结论：换幼儿园改不动峰的位置。
  3. φ(a) 的子女窗口（30–52 岁）与 n_c/n_a = 0.5。全模型里对总量影响最大的单一参数：φ 从 1.00 到 1.13，对应 45 岁每人每年 +7,200 元，占其自身消费的 11%。窗口右移 2 年，30–34 段下调约 5%。

口径

0–17 岁是家庭代付：一根柱子 = 一个家庭为这个孩子一年的支出，不是孩子自己花的钱。18–22 岁是学费 + 住宿 + 生活费，独立构造、不含房租本金。23 岁起是本人消费（户均 × 成人份额调整）。18 岁那个 −7.8% 的台阶，一半是口径切换（从家庭支出转为个人支出），不是真实的消费断崖；扣除口径差之后，真实降幅比它更小。22 → 23 岁则相反：那是一个向上的 +14.0% 的缝，一半是毕业后的真实变化，一半是「住校 → 租房」的口径切换。

每户视图是另一张表：横轴换成户主年龄 22–85，柱高是一户人家一年的总支出（元/户/年），由人均表按户均人口加总得到。官方同样没有「户主年龄 × 消费」的交叉表，每一格也是估算；户均人口按户主年龄取 1 / 2 / 3 / 2 / 1.4 人的构造值。加权户均 125,560 元对锚点 127,554 元偏离 −1.56%——v1 的 +0.79% 是巧合抵平，不是精度。
