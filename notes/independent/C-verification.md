### P0-1：修好了方向，但 φ 不是证据

- 数字对：`data/shanghai_lifecycle.csv` 46 岁 = 64,597.9，30 岁 60,017.2，34 岁 63,264，40 岁 64,221。
- 机制是 `model-spec.md:154-172` 的 φ(a)：`c_adult = h + (n_c/n_a)(h − c_kid)`，φ 从 1.000（23）→1.071（30）→1.127（45）→1.013（55）→1.000（60+）。
- **问题 1：φ 是恒等式的残差，不是估计。** `h(a)` 本身是"knots 插值 + 平滑"（`model-spec.md:148`），`c_kid` 是模型篮子（约 4.1 万），两个输入都是模型曲线；用它们相减得到的 φ 不构成对现实的独立验证。`model-spec.md:172` 说"不是拍的，是恒等式推出来的"——恒等式保证的是代码自洽，不是经验正确。
- **问题 2：峰位 46 是 φ 的 argmax（45）决定的。** 只要 φ 在 45 岁达峰，全局峰就在 45–46，模型没有能力产出别的峰位。所以"46 岁是人生最贵"不是发现，是参数。
- **问题 3：零和。** 总量钉死在 54,980，任何一段抬高都是别段让出。我按人口加权算了 13 段的净贡献（元/人）：30–39 **+3,033**、40–49 **+2,120**、23–29 **+338**（合计 +5,492），由 60–69 **−2,130**（ρ）、0–17 **−1,527**、70–79 **−925**、50–59 **−894**（φ 回落）让出（合计 −5,476，余 −16 来自 18–22）。**去掉 60 岁硬崖，60+ 整体抬高 11.1%，重归一后 30–49 人均回落约 1,600 元（−2.5%）**，峰位不变但高度降。
- 判定：**方向对（v1 的"59 岁峰"确实是分母假象），但"修好"的幅度是三个假设（φ 窗口、n_c/n_a、ρ）合谋的结果，证据等级 B/C，不是 A。**

## 2. 七个指定怀疑点

### 2.1 60 岁的 −10.44% 是不是"乘出来的"

是，见 P0-5。补充两点量化：

- 60–69 段均值 48,623.0；若 ρ 改为 5 年 glide（60: 0.970 / 61: 0.945 / 62: 0.925 / 63: 0.910 / 64+: 0.900），60–69 均值升到约 **50,330（+3.5%，+1,707 元）**，全市 **+233 元（+0.42%）**，由 λ≈0.9958 吸收，30–49 各降 0.4%（30–39 62,901→62,637）。
- 台阶改成 glide 后，59→60 变 −3.0%，60→64 累计 −10%，"崖"变成"坡"，读图不会再误认为某一年发生了消费断裂。

### 2.2 0 岁用品 24.6%（7,999 元）：是不是又一版"四等分"

**不是四等分，但是配平项，而且量级偏高 45–78%。**

- 数据：0/1/2 岁用品 7,999.3 / 7,941.6 / 7,110.6，占 24.6% / 24.5% / 22.1%；3 岁骤降到 5,089，4 岁 4,240（0→4 −47%）。
- 我的婴儿篮子先验：用品 4,500–5,500（尿不湿 2,000–2,500 + 推车/安全座椅/童床摊销 2,500–4,000 + 玩具 800）。A 的先验是 15%（按他的 30,000 即 4,500）。**7,999（0–2 均值 7,684）比双方先验高 45–78%。**
- 结构性问题：推车/童床/安全座椅是**一次性**支出（8,000–15,000），模型把它当作 0、1、2 岁各 8,000 的**年流量**，三年合计约 **2.3 万**——同一辆推车被计了三次。对一个"1 岁儿童家庭"的横截面均值，合理的耐用品支出是 3,000–4,000/年。
- 它为什么被抬高：对比 v1，0–2 的医疗 −10,556、居住 −9,098，用品 +4,582。**总篮子先定在 32,500，用品是被用来补缺口的那个格子**（`REBUILD-LOG.md:17` 的原话是"用品（奶粉尿布推车）反而升到 24.6%——这才是婴儿的真实结构"，这句话本身没有证据，只有断言）。
- 修正到 6,500/5,800/5,200 的效果：0–2 均值 32,386→**30,535（−5.7%）**，谷从 32,186 降到 **30,275**，峰谷比 2.01→**2.13**，全市只 −32 元（−0.06%，λ 吸收）。若同时把医疗从 1,300 提回 2,200（+897）：0–2 均值 **31,432（−2.9%）**、谷 **31,152**、峰谷比 **2.07**，**对 A 的 0–2 原始值从 +8.0% 收敛到 +4.8%**。

### 2.3 23 岁居住 43.25%（23,712）——B 的判定还成立吗

**不成立。我上一轮的判定错在基准不一致，这里更正。**

- B 当年说"居住金额对得上（+14.5%）"：那是拿 v1 的 22,319 比 **未折算** 的 A 19,500；同一段又说"总额 52,978 低于 A 的 65,000"，用的是**未折算**的 A。两个比较都没问题，但 v2 把总额锚到了 54,821（对 A 折算值 56,331 只差 −2.7%），**分母修好之后，43.25% 就不再是分母假阳性**。
- 现在的事实：居住 23,712 vs A 原始 19,500 = **+21.6%**；vs A 折算 16,900（19,500×0.8666）= **+40.3%**。23–34 岁居住占比一直在 42–43%（30 岁 42.99%、34 岁 42.56%），12 年不降。
- 水平本身可辩：23,712 = 1,976 元/月（含水电），上海合租单间 2,000–3,500/月，**这个数不高**；同岁食品 13,115（1,093/月）、交通 5,899（492/月）也自洽。A 的 35% 上限是他按 65,000 总额反推的，**不是独立的经验上限**。
- 真正错的是**台阶**，不是水平：22 岁 4,200（宿舍）→23 岁 23,712（租房），一年内居住 ×5.6。见 P0-3。
- 所以我的新判定：**"占比"不是假阳性，是真实的建模选择（偏高但可辩）；"22→23 的 +27.5%"是假断崖，必须修。**
- 修法（不动 23 岁水平）：22 岁设过渡年，总额 43,000→46,000（求职/搬家/毕业过渡 +3,000，居住按 6,000 记）；23 岁居住 23,712→21,000（1,750/月，仍合理）。结果：22→23 从 **+27.5% 降到 +13.3%**，21→22 从 0 变成 +7.0%，全市净效应 ≈ **−16 元（−0.03%）**，不破坏锚点。

### 2.4 30–49 的 φ：有依据的等价规模，还是调出来的

**是"有代数依据、无经验依据"的残差；不能从户表独立复算；而且它把两个概念混在了一起。**

- 恒等式本身没错：`n_a·c_adult + n_c·c_kid = (n_a+n_c)·h` ⇒ `c_adult = h + 0.5(h − c_kid)`（`model-spec.md:156-164`）。
- 但三个输入全是模型量：`h(a)` 是 knots 插值（`:148`），`c_kid` 是 0–22 篮子加权均值 4.1 万，`n_c/n_a = 0.5` 是"上海三口之家为主"的断言（`:164`）。**φ 的全部经验内容只有两个数：一个孩子成本 ≈ 户均的 75%，每两个成人一个孩子。** 这两个数我认为方向可信（上海 0–22 养到大学毕业的年均成本确实接近人均消费的 70–80%），但没有任何本项目的独立证据。
- **不能从户表复算**：户表 H(a) = c(本人) + c(配偶) + c(子女)，是 c(a) 的加总。35 岁 H = 63,501 + 62,906 + 39,124 = 165,531 = 3 × 55,177。所以"用 H 反解 φ"得到的必然是 φ 自己（`check_rebuild.py:151-161` 的检查 6 就是这条恒等式，属自洽测试，不是外部检验）。
- **概念混用**：φ 是"把户均拆成成人自身消费"，但 v2 把 φ(a) 当成个人生命周期曲线来用。后果是**孩子离家被翻译成"成人消费下降"**：40–49 均值 64,436 → 50–59 58,749（**−8.8%**），而 φ 从 1.127（45）降到 1.013（55）就是 **−10.1%**——这一段下降 100% 由 φ 的回落解释，没有任何消费证据。一个人的自身消费不会因为孩子搬走而下降 10%（只有住房/耐用品会）。
- **反向补偿**：户表已知重复计算户内公共品 8,000–12,000/年（`model-spec-household.md:173`），即每个成人多算 4,000–6,000。若扣掉，成人 c 降约 3%，φ(45) 应从 1.127 降到 1.09 附近——**φ 里约有 0.03–0.04 是在给重复计算打补丁**，两个错误部分对冲，无法分别识别。
- 判定：**φ 作为"户均→成人"的会计分解是成立的；作为"30–49 成年人更富"的行为结论是不成立的。** 图上的 30–49 驼峰应标注为"家庭构成效应"，不能写成"中年人自己花得多"。

### 2.5 老年教文 9.3–9.6%（70 岁 4,526）

**不是"教育没退干净"，也不是偏高——A 给 11%，我们还低 1.4pp；缺证据的只是"70 岁比 45 岁更高"这一步。**

- 官方八类的这一列是**教育文化娱乐**，不是"教育"。45 岁 5,596.7、70 岁 4,525.9、85 岁 3,214.0（占比 8.7% / 9.62% / 7.43%）。
- 孩子的学费记在**孩子自己的行**（6–17 岁教育 12,600–13,700），不在父母行。所以 70 岁的 4,526 是纯成人文娱（电视/手机/旅游/老年大学/棋牌），**没有教育残留**。
- 但模型给了它一个上翘的梯度：`model-spec.md:193` 教文在 70 岁 = 1.10（45 岁 = 1.00），形态标注"老年文娱回升"。占比 8.7%（45 岁）→ **9.62%（70 岁）→ 7.43%（85 岁）**。**A 的先验是 70–85 教文 11%（5,060），我们 9.62%（4,526）——比 A 还低 1.4pp**，所以"偏高"不成立，方向也一致。真正没有独立证据的是"70 岁占比高于 45 岁"这一步（由梯度 1.10 造出来）。
- 金额可辩（4,526 = 377/月）。金额 45→85 从 5,597 降到 3,214（−42.6%），但 85 岁不旅游、不上老年大学，实际该降 60%+，85 岁的 7.43% 略高（建议 6.0% 量级）。
- 判定：**P2，"假设"而非"错误"；"老年文娱回升"与 A 方向一致，但没有独立证据，不能当作发现。**

### 2.6 18–22 四年完全平坦 43,000

**不真实，是构造块；而且它是 23 岁断崖的承重墙。**

- `shanghai_lifecycle.csv:20-24` 五行完全相同（12,500/2,400/4,200/2,200/3,400/12,000/1,850/4,450/43,000）。`model-spec.md:121-136` 明说这是"学费 5,500 + 住宿 1,200 + 生活费 30,000 + 书本 6,500 + 寒暑假水电 3,000"的构造值。
- 真实的大三大四：实习/兼职收入、求职与搬家成本、毕业旅行、租房押金，高年级支出应高于低年级，22 岁（毕业年）尤其高。**四年零斜率是一个简化，不是一个估计。**
- 它的后果是承重的：22 岁停在 43,000，23 岁跳到 54,821。若 22 岁记 46,000，跳幅就从 +27.5% 降到 +19.2%。
- 判定：**P1，"假设伪装成数据"。要求：明确标注为构造块，并给 3–4% 的年级斜率（大一 42,000 → 大四 45,500，均值不变）。**

### 2.7 户均 −1.563% 的 WARN

**同意"不是人均曲线的错"，但不同意"只是构成规则的错"就完了；家庭口径那版不可作水平引用。**

- 人均层是真的：我独立复算加权 54,980.00，八类逐一精确。所以 `check_rebuild.py:165-171` 的 6b 与人均曲线无关，这条我同意。
- 但归因不完整。我拆开：`54,980 × 2.3029 = 126,614`，实际户均 125,559.87，隐含人均 **54,522（−0.83%）**；即使把户均规模换成七普 2.3168，仍差 **−1.43%**。所以 −1.563% 里只有 **−0.74pp 是规模**，其余 **−0.83pp 是"构造成员的年龄分布"与真实人口不一致**（孩子/配偶的年龄按 `子女 = 户主 − 30`、`配偶 = 户主 − 2` 生成，隐含的家庭成员集不是上海人口）。
- 构成偏离是硬伤：一人户 **11.07% vs 七普 28.37%**、三人户 **47.16% vs 22.39%**、四人及以上 **0 vs 14.69%**（`household_size_by_age.csv` 每行 note 自认）。这不是"差一点"，是把分布压成了 2–3 人户的单峰。
- 后果：户表的两个台阶全是规则产物，不是生命周期事实——
  - 52→53：168,054.2→122,507.0（**−27.1%**），人均反而 56,018→61,254（**+9.35%**）；
  - 69→70：95,263.1→66,100.9（**−30.6%**），人均只 47,632→47,215（**−0.87%**）。
  - **70 岁的"老年消费崩掉"是 2 人 →1.4 人的除法，不是消费下降。**
- 可用性判定：**户表 = c(a) 按合成家庭结构的加总，不是户均观测。** 水平（17.6 万）不可引用，形状（53/70 两个崖）不可解释，只能作为"给定这套合成结构"的示意，且必须注明。**"家庭口径"这一版不可用作对外结论。**

## 3. 新引入的问题

### 3.1 断崖清单（|单年变化| > 10%）

| 年龄 | v1 | v2 | 性质 |
|---|---|---|---|
| 2→3 | +16.82% | **+20.91%** | 幼儿园入学（教育 1,331→9,069） |
| 5→6 | −10.96% | **+11.12%** | 小学入学（教育 9,256→12,544） |
| 17→18 | **−25.12%** | −7.82% | 口径缝（大学） |
| 22→23 | +21.79% | **+27.49%** | 口径缝（宿舍→租房） |
| 59→60 | −0.57% | **−10.44%** | ρ 硬编码 |

v1 有 5 处 >10%（1→2 +12.77、2→3 +16.82、5→6 −10.96、17→18 −25.12、22→23 +21.79），v2 有 4 处；但 **v2 的最大向上跳变（+27.49%）比 v1 更大**，且 2→3、5→6 都变大了（5→6 从下跌翻成上涨）。**"消除断崖"这个说法不成立，只能说"最大的向下断崖变小了"。**

### 3.2 四个拐点全是家庭事件，不是消费事件

30 岁（+2.48%，孩子出生，φ 启动）、53 岁（−2.62%，孩子离巢，φ 归零）、59→60（退休，ρ）、22→23（成户，口径切换）。**这四个之外，只剩 2→3（+20.91%）、5→6（+11.12%）、17→18（−7.82%）三个入学/口径节点；再把这三处看作制度性台阶，全表其余年份的变化都在 2.6% 以内。** 换句话说：这条"个人生命周期曲线"的所有转折，要么由家庭构成规则驱动，要么由学制驱动，没有一处来自消费行为本身。

### 3.3 单调性检查是"构造性通过"，不是检验

- 医疗 23–85 严格单调（0 次下降）：因为 `s_cat` 医疗梯度是 0.34→4.50 的单调指数曲线（`model-spec.md:194`），生成出来必然单调。
- 居住 34 岁后单调降（最大回升 0.00%）：同理，梯度 1.17（30）→0.60（85）单调。
- `check_rebuild.py:127` 还给医疗单调留了 0.5% 噪声窗口——**一条构造上不可能失败的检查**。

### 3.4 IPF 只能平移不能改形状

`calibration.band_scaling_pct`：23–39 食品 −3.5%、交通 +3.8%、医疗 −4.7%、居住 +2.6%，最大 6.07%。**同一带内所有年龄共用同一个带级因子**（`model-spec.md:152`），所以带内形状 = 参数曲线，IPF 只能改带的高度，改不了带内的斜率和拐点。它校正的是"八类列和"，不是"年龄形状"。**把 IPF 当作形状验证是误读。**

### 3.5 其他细节

- 教育 16 岁与 17 岁**完全相等**（13,700.0），JSON `acceptance.education_peak_age = 17`，`check_rebuild.py:118` 说 peak 16——数据本身是并列平顶，两个"峰"都对，但说明这一段也是平的。
- 85 档是 **85–100 合并**（`check_rebuild.py:56-58`）。所以"85 岁医疗 14,943"实际是 85–100 岁的均值，`REBUILD-LOG.md:198` 自认被 86+ 拉高约 3%。**它是 16 年的平均，不是 85 岁这一年。**
- 85 档（85–100 合并）权重 **w = 0.0198**：85 岁医疗每变动 5,000 元，全市均值只动 **99 元（0.18%）**，远小于 IPF 的 ±15% 闸门。**这一格受锚点约束很弱，4.50 这个梯度值本质上是自由参数，不是被标定出来的。**
- 22→23 的"其他"从 4,450 掉到 1,812（−59%），因为 18–22 的"其他"含寒暑假水电/社交，23 岁后归零。这也是口径切换的一部分，未标注。

## 5. 系统性问题

1. **零和重切，不是新证据。** 总量钉死 54,980，重建本质是把同一块蛋糕重新分配（人口加权净贡献，元/人）：0–17 让出 **1,527**（0–2 −249、3–5 −414、6–11 −491、12–14 −185、15–17 −188），50+ 让出 **3,954**（50–59 −894、60–69 −2,130、70–79 −925、80–85 −5），18–22 −12，换来 23–49 的 **+5,492**（23–29 +338、30–39 +3,033、40–49 +2,120）。**这不是"发现了新数据"，是"换了分配规则"。**
2. **人均口径与户均口径混用。** 0–17 是"孩子自己的篮子"（人均），18–22 是"家庭代付的总额"（户均性质），23–85 是"φ 拆出来的成人份额"（户均分解）。三种口径缝在 18 和 23 两处，正好是两个最大的断崖。
3. **户表是产物，不是证据。** H(a) ≡ Σ c(成员)，所以户表的水平、斜率、台阶全部由 c(a) + 构成规则决定；`check_rebuild.py:151-161` 的"户内一致性"是循环验证。
4. **70–85 段靠三个数撑着**：医疗梯度（85 岁 4.50）、居住梯度（85 岁 0.60）、85 岁医疗的 4,000 元长护外溢。没有分年龄调查，也没有上海老年消费的独立锚。这一段是外推，不是估计。
5. **RAS/IPF 抹平的是带级水平，不是年龄差异**；且 ±15% 闸门意味着任何超过 15% 的修正都会被拒绝（`REBUILD-LOG.md` 说 S1 食品反事实要 −34.2%，直接 SystemExit）。**闸门保护了锚点，也锁死了纠错空间。**
6. **"没有证据的假设"清单**（应标注为假设，不能写成估计）：
   - 60 岁 ρ = 10%（硬编码，一年内）；
   - φ 的 n_c/n_a = 0.5 与 30–52 窗口（`REBUILD-LOG.md:174` 自认"全模型对总量影响最大的单一参数"）；
   - 0–2 用品 8,000/年（配平项）；
   - 18–22 四年平坦 43,000（构造块）；
   - 70–85 户均 1.4 人（0.4 配偶存活期望是拍的，`model-spec-household.md:156`）；
   - 85 岁医疗的 4,000 元长护外溢（无来源）；
   - 老年教文梯度 1.10（"文娱回升"无证据）；
   - 幼儿园 5,000/12,000 两档（真实分布未知）；
   - "无四人及以上户"（七普 14.69%）。
7. **85 岁医疗不是"低估"，是"标签错"。** 14,943 = 居家医疗约 11,000 + 长护外溢约 4,000（`model-spec.md` §7）。**去掉 4,000，11,000 正好落在 A 的居家区间 10,600–11,500 内——所以按口径对齐，这一格与 A 一致，不存在系统性低估。** 问题在于：(a) 标签写"居家"却含 4,000 照护；(b) 官方医疗保健列不含长护，这 4,000 被塞进了 NBS 口径的医疗；(c) 含机构/外溢的长护档只到 17,943（+3,000 档），仍低于 A 的机构区间下沿 18,000；只有整套 high 情景（健康类 ×1.3）才折算到约 19,426，勉强进入。**如果受众问的是"含机构护理"，这一格仍然低 17–40%**（vs 机构下沿 18,000 低 17%，vs 上沿 25,000 低 40%）。

## 6. 判决与三处再改

### 判决：**有条件可信**

- **A 级（可作锚点）**：54,980 加权总量、八类官方额、23–39 岁 5.6–6.3 万的平台、0–2 岁 3.2 万的谷、85 岁医疗的量级（按 11,000 居家口径）、户均规模 2.30。这些我独立复算通过，且与 A 的盲测在 ±1% 内吻合。
- **B 级（方向可信、数字不可引用）**：30–49 的驼峰（φ）、60+ 的医疗爬坡、居住 23–35 的 42–43%、老年教文 9–11%（与 A 的 11% 接近）。
- **C 级（假设）**：22→23 与 17→18 的口径缝、59→60 的台阶、18–22 的平坦、0–2 的用品结构、70–85 的外推。
- **一句话**：**这张图能讲"钱在人生里怎么被家庭结构重新分配"，不能讲"哪一年花了多少钱"。**

**能讲**：育儿期是现金流的第一道刚性挤压（0–17 年支出 3.2→4.7 万，占三口之家支出约 1/4）；23–35 岁住房占 42–43%；成年自身消费平台 5.6–6.4 万；60 岁后医疗从 6,000 爬到 15,000；老年不崩（人均 70–85 只比 60–69 低 7.6%），崩的是户均（1.4 人的除法）；18 岁和 23 岁是两个口径，不是一个断崖。

**不能讲**：任何单年数字（18 岁、22→23、59→60、2→3）；"46 岁是人生最贵"（那是 φ 的 argmax）；"60 岁消费降 10.4%"（100% 硬编码）；"85 岁医疗 14,943"（是 85–100 的均值 + 含 4,000 长护）；"上海家庭峰值 17.6 万"（合成结构）；"4 岁最贵"（已推翻）；"30–49 岁最穷"（已推翻，且反转）。

### 最该再改的三处

**① 22–23 的口径缝（唯一负分的 P0）。**
22 岁总额 43,000→46,000（居住按 6,000 记，补求职/搬家/毕业过渡 3,000），23 岁居住 23,712→21,000。
效果：22→23 从 **+27.5% 降到 +13.3%**；21→22 从 0 变 +7.0%；23–29 段均值 56,136→55,749（−0.7%）；全市净 **−16 元（−0.03%）**，λ 不动。**把"23 岁突然变富"的观感消掉，同时保住 1,750/月的租金水平。**

**② 60 岁的 ρ 台阶改成 5 年 glide。**
ρ：59 = 1.000、60 = 0.970、61 = 0.945、62 = 0.925、63 = 0.910、64+ = 0.900。
效果：59→60 从 **−10.44% 变 −3.0%**，60–64 累计 −10%；60–69 均值 48,623→**50,330（+3.5%）**；全市 **+233 元（+0.42%）**，λ 0.9958，30–49 各降 0.4%（30–39 62,901→62,637）；峰仍在 46。**把"崖"讲成"坡"，且不再需要自设的 [−18%, −8%] 验收窗口。**

**③ 0–2 篮子重配：用品 8,000 → 6,500/5,800/5,200，医疗 1,300 → 2,200。**
效果：0–2 均值 32,386→**31,432（−2.9%）**；谷 32,186→**31,152**；峰谷比 2.01→**2.07**；全市 **−12 元（−0.02%）**；用品占比 24.6%→**18.6%**、医疗 4.0%→**7.0%**（A 是 10%）；**对 A 的 0–2 原始值从 +8.0% 收敛到 +4.8%**。**一次改掉"用品 8,000"和"医疗 1,300"两个最容易被专家一眼看穿的格子。**

> 零成本附加项（不需要重标定，只改标注）：把 85 岁医疗拆成"医疗 11,000 + 居家照护 4,000"，把"85 岁"改成"85–100 岁"，把 18–22 标注为"构造块"。
