## 1. 改了什么（逐条对 P0）

### P0-1　0–2 段结构是假的

**症状**：0 岁医疗 12,066（占 22.9%），食品 12,081；23 岁食品才 11,529。婴儿"吃"得比青年多，医疗每月一千。

**根因**：v1 拿育娲 0–2 岁总额 21,559 × 上海倍数 2.2298 = 48,072，再按「食品 25 / 居住 25 / 医疗 25 / 其他 25」四等分。可育娲的 21,559 **就是 2019 年全国人均消费支出**——它压根不是婴幼儿篮子，是成人篮子。四等分只是把这个错误放大。

**改法**：0–17 岁改成**逐带、逐类的绝对额篮子**（spec §3.2），0–2 岁 = 食 12,500 / 衣 1,400 / 住 3,500 / 用 8,000 / 行 1,300 / 教 1,200 / 医 1,300 / 其 3,300 = **32,500**。医疗占比从 22.9% 降到 **4.0%**，用品（奶粉尿布推车）反而升到 24.6%——这才是婴儿的真实结构。

**实测**：0 岁医疗 **1,300**，0 岁食品 12,500 < 23 岁食品 13,115。✅

### P0-2　30–49 被家庭分母摊薄

**症状**：30–39 均值 48,014、40–49 均值 52,196，比 50–59（64,898）低 1.6–2.4 万；成年峰被推到 59 岁。而居住**金额**（23/30/45 岁）与独立先验是对得上的（+14.5% / +5.3% / +0.4%）——错的只有总额。

**根因**：v1 用"家庭消费 ÷ 家庭人数"。孩子的消费只占成人的 60%，一分母就把成年人自身的消费压低了 10–20%，而且**越是有孩子的年龄压得越狠**，于是曲线在中段凹下去、在 59 岁（孩子离家）翘起来。这不是行为，是算术。

**改法**：引入**成人份额调整因子 φ(a)**（spec §5.2），由恒等式推出来：

```
n_a·c_adult + n_c·c_kid = (n_a+n_c)·h
⇒ φ(a) = 1 + (n_c/n_a)·(1 − c_kid/h)，n_c/n_a = 0.5（30–52 岁平滑窗）
```

φ 不是常数：23 岁 1.000 → 30 岁 1.071 → 45 岁 1.127 → 52 岁 1.075 → 60 岁 1.000。

**实测**：30–39 **62,901**（+31.0%）、40–49 **64,436**（+23.4%）、50–59 58,749（−9.5%）。成年峰从 59 岁移到 **46 岁**。✅

### P0-3　18 岁 −25.1% 是口径切换的假断崖

**症状**：居住 17→18 岁 11,619 → 3,002（−74.2%）、教育 20,324 → 11,788（−42.0%），总额 −25.1%。

**根因**：17 岁的居住里含"家庭住房分摊"（v1 把成人的 22,319 按 0.52 折给孩子），18 岁突然切到"住校 3,002"；教育同理（17 岁含高中补课的家庭分摊，18 岁切到学费 5,500+住宿 1,200）。**两个口径在 18 岁硬拼在一起**，图上就是一个断崖。

**改法**：0–17 的居住只含"孩子分摊的水电物业"（3,500–4,700），18–22 的居住只含"校内住宿 + 寒暑假在家水电"（4,200）。两端同口径，落差自然消失。教育同理：17 岁 13,700（高中+补课）→ 18 岁 12,000（学费+书本），−12.4%。

**实测**：17→18 岁 **−7.82%**（46,650 → 43,000），其中居住 4,700 → 4,200（−10.6%）、教育 13,700 → 12,000（−12.4%）。✅（略浅于"8–12%"，见 §6）

### P0-4　4 岁峰是 12,000 幼儿园假设的产物

**症状**：4 岁 71,060，只比 59 岁 68,150 高 4.27%。

**根因**：两层叠加。(a) 育娲 3–5 岁总额 33,559 里含 12,000 的幼儿园加项，×2.2298 后变成 26,760；(b) 0–2 岁又用了成人口径的 48,059。两段一起把学龄前抬到 6.8 万，比成年还高。

**改法**：幼儿园 base 用**公办 5,000**（上海公办园保育费 + 餐费，民办 12,000 放敏感性），3–5 岁教育 9,200；同时把 0–2 岁拉回 32,500。

**实测**：4 岁 **38,660**，全局峰 46 岁 64,598。敏感性显示：**即使把幼儿园换回民办 12,000（+7,000），峰仍在 46 岁**（`sensitivity_kindergarten.json`）——说明 4 岁峰的主因是**水平**（育娲总额×2.23），不只是幼儿园那 7,000。这一条比审计的表述更强：只改幼儿园改不动峰，必须同时重建 0–2/3–5 的水平。✅

### P0-5　60 岁没有退休断崖

**症状**：59→60 只 −0.57%，50–59 → 60–69 只有 −1.0%。

**根因**：v1 的老年折减是 `1 − 0.28×smoothstep(58,85,a)`，在 60 岁几乎还没启动；真正把 60+ 拉低的是"孩子离家"的机械效应，恰好抵消了退休下降。

**改法**：显式退休台阶 `ρ(a) = 1 − 0.10·smoothstep(59,60,a)`，一年内下移 10%；再用医疗/交通的构成梯度把 60+ 的结构改对（医疗占比 10.6% → 34.5% @85，交通 10.5% → 6.0%）。

**实测**：59→60 **−10.44%**；60–69/50–59 = **0.828**。✅

## 6. 三个最脆弱的假设

1. **23–30 岁的居住金额（≈23,700 元/年）**。它是 v1 留下的、审计判为"与先验相符"的列，本轮没动。但重建后 23 岁总额降到 54,821，居住占比升到 **43.3%**，超过盲测先验"≤35%"的上限——**这是全表唯一一条没通过 A 清单的格**。要压回 35% 需要砍到 19,200（−19%），会突破 ±15% 闸门且与审计结论冲突，所以选择保留并标注。若上海的年轻租客实际更依赖合租（居住 15,000–18,000），23–29 段整条曲线要下移 4,000–6,000。
2. **3–5 岁的幼儿园口径（公办 5,000）**。base 用公办，民办 12,000 放敏感性。这不影响峰的位置（两种口径峰都在 46 岁），但影响 3–5 段的绝对水平（38,899 vs 45,899，±18%）。上海民办园占比若高于 30%，这一段应上调 2,000–4,000。
3. **φ 的子女窗口（30–52 岁）与 n_c/n_a = 0.5**。它决定 30–54 段整体高度：窗口右移 2 年（32–54），30–34 段下调约 5%、34–38 段上调约 3%；若上海实际更接近"二胎家庭 n_c/n_a = 1"，该段要再上移 6–8%。**这是全模型对总量影响最大的单一参数**（φ 从 1.00 到 1.13，对应 45 岁每人每年 **+7,200 元**，占其自身消费的 11%）。

（第四顺位的敏感参数：退休降幅 10%。它在 [8,18] 窗口内取下沿，因为上海老年人有较强的代际转移。改成 15% 会让 60 岁降幅变成 −15.2%，仍在窗口内。）

## 7. 走过的弯路（可复现的教训）

1. **φ 的系数写错了一次**：第一版用 `s = n_c/(n_a+n_c) = 1/3`，而恒等式要求 `n_c/n_a = 1/2`，φ(45) 只有 1.085（应为 1.127）。发现方式不是"看起来不对"，而是**户内一致性检查**：`2c(35)+c(5)` 与 `3h(35)` 差 −7%，一算就露馅。改成 n_c/n_a 后 λ 从 1.0334 降到 1.0131，30–49 段整体上移约 4%。→ **教训：恒等式是最好的单元测试。**
2. **教育平滑核漏气**：带间平滑用 σ=0.75，结果 3–5 岁的 9,200 泄漏到 2 岁，教育 0–2 最大值变成 3,379，卡在验收线上。改成教育单独 σ=0.35，2 岁降到 1,331。→ **教训：制度性台阶（入园、入学、退休）不能用统一的平滑核。**
3. **医疗梯度平滑吃掉了退休台阶**：σ=1.0 的核把 59→60 的医疗跳变抹平，出现"退休后医疗下降 3.8%"的假象，单调性检查直接挂。改成医疗专用 σ=0.35。→ 同上。
4. **85 岁医疗追了三次**：2.75 → 13,556；4.00 → 14,112；4.50 → 14,943。每调一次列和都变，λ 也跟着动（因为医疗列被 IPF 压回 4,570，其他列要补）。→ **教训：单格调参在 IPF 下是耦合的，必须每次重跑全表验收，不能只看那一格。**
5. **幂等性差点没过**：早期版本用 `dict` 迭代 + 浮点累加顺序不稳，md5 会变。改成固定顺序的 numpy 向量化后逐字节一致。→ **教训：把幂等当验收项，而不是当"应该没问题"。**

# v3：按 C 复核再改三处（2026-11）

## 10.1 复核判决与为什么只改三处

`notes/independent/C-verification.md`（273 行）的判决是**「有条件可信」**：方法方向对（分项篮子、φ、IPF 闸门、居住硬约束），但有三个格子/参数被点名"不是算出来的，是写出来的"。父 agent 明确要求**只改这三处，其余不动**，理由很实在：v2 已经有 21/22 项通过，全面重做会把"可辩护的部分"和"不可辩护的部分"一起搅浑，复核者也分不清哪一版是哪一版。

三处的共同点：**它们都是"参数里藏着答案"**——ρ 写死 −10% 然后验收 −8~−18%；23 岁居住定 23,712 然后接受 +27% 的跳变；0 岁用品 8,000 是为了让 0–2 总额落在 32,500 的配平项。v3 的改法不是把数字调到"看起来好"，而是**把答案从参数里拿掉，让结果由结构产生**。

## 10.2 ① 22–23 的口径桥（P0-3 的残余）

**v2 的病**：22→23 = +27.49%（43,000→54,821），居住 4,200→23,712 一个人贡献 165% 的跳幅。18 岁的 −25.1% 假断崖修好了，但缝挪到了 23 岁，还更大。C 复核的原话是"修 P0-3 修出了一个新的、更大的 P0-3"。

**v3 的改法**（三个旋钮，全部可解释）：

| 旋钮 | v2 | v3 | 依据 |
|---|---|---|---|
| 22 岁总额 | 43,000 | **46,000** | 毕业年真实发生一次性成本：租房押金/半年租金 1,800 + 求职、搬家、置装 1,200 |
| 23–26 居住系数 | 1.00 | **0.86 / 0.90 / 0.94 / 0.97** | 合租/次卧 → 整租的爬坡，不是毕业即整租 |

**没有消除的部分**：+13.96% 仍是向上的跳变。这是**口径事实**——22 岁住宿舍、23 岁在上海租房——不是形状错误。v3 的处理是把它标成"桥"、单列 INFO、写进 basis 和 note，而不是假装它不存在。要彻底消除只能假设"毕业生不租房"，那是更假的假设。

## 10.3 ② 退休台阶：删掉硬乘子，改 5 年 glide（P0-5 的残余）

**v2 的病**：`ρ = 1 − 0.10·smoothstep(59,60,a)`，一年下移 10%。C 复核把 ρ 拿掉重算，59→60 只剩 **−0.49%**——说明那条 −10.44% 的"退休崖"**整根都是参数，不是结构**。更糟的是验收窗口 [−18%,−8%] 是在看到 −10.44% 之后设的，还顺手把 18 岁排除掉。

**这句话必须写在这里**：**v2 的 −10.44% 是自设窗口的产物，v3 删除该窗口。** 不是"v2 算错了 6.97pp"，是"v2 用参数生产了一个数字，再用一个恰好装得下它的窗口宣布合格"。

**v3 的改法**：

```
ρ(a) = np.interp(a, [59,60,61,62,63,64,85], [1.000,0.970,0.945,0.925,0.910,0.900,0.900])
```

五年走完 −10%，之后平台。依据：退休是渐进的（部分退休、返聘、配偶先退），消费调整跨 3–5 年；国际实测的 −10~−20% 本身就是**多年累计**口径，不是一年。

**验收改为两条事先可辩护的规则**（`check_rebuild.py`）：

- **(a)** 任何相邻年降幅 ≤ 8%，18 岁与 23 岁两处口径桥除外（桥必须单列报告 + 给出桥接解释）；
- **(b)** 全局峰之后单调不增。

这两条不依赖任何实测答案，也不给"刚好通过"留空间：8% 是"同一口径内不应该有台阶"的常识上限，单调性是"46 岁之后不该再涨"的结构断言。

实测：59→60 **−3.47%**（55,607.0→53,677.1）；59→64 累计 **−12.39%**；60–69/50–59 = **0.842**。也就是说，**退休的消费下移仍然存在，只是分散在 5 年里**；把它压进一年才是 v2 的错误。

## 11.1 D 抓到了什么

**① 2→3 岁 +24.92%，反成全表最大跳变。** v2 是 +20.91%，v3 修 0–2 篮子时把它**改大了**：v3 把 0–2 教育压到 1,200（沿用 v2 的"绘本/早教"），却把医疗抬到 2,200、用品抬到 6,500，于是 2 岁总额被推高、3 岁不变，台阶从教育一侧被撬得更陡。教育 1,330.6 → 9,069.4，贡献 **99.7%** 的毛跳幅；医疗 2,200 → 1,376.6（−37.4%）反向放大净跳幅。根因不是平滑参数，是**假设本身错了：三岁前育儿不是免费的**。

**③ glide 端点 0.900 是选的。** 复核给了 0.85 / 0.90 / 0.95 三档，要求落成文件。

## 11.2 ① 补 0–2 岁托育：`INFANT_EDU`

v3 的 0–2 教育 1,200 隐含"三岁前育儿免费"，而上海 2 岁托班 2,000–6,000 元/月。v4 改成"入托率 × 月费 × 12 + 早教参与率 × 年支出"：

## 11.7 这一轮的五条教训

1. **检查项本身会有方向性盲区。** `if v < 0` 只查跌幅，于是三个"上涨"型断裂全部漏网。验收规则要先问"它能不能发现反方向的错误"，而不是"它能不能装下我这版的结果"。
2. **改一处要重看全表 Top3。** v3 只盯着"0–2 医疗/用品"两格，没注意 2 岁的分母被同时推高。任何局部改动后，第一件事是把全表排序打印出来。
3. **日志里的数字会自己过期。** `REBUILD-LOG.md:272` 写着 v2 的 +20.9%，产物是 +24.92%，两者并存了整整一版。数字必须由脚本生成或由脚本校验，手抄的必然漂移。
4. **谷的位置是假设的函数，不是数据的性质。** 补托育前谷在 2 岁、补后在 0 岁；如果入托率改成"0 岁 5%"，谷会回到 2 岁。报告谷时必须同时报告"它由哪个假设决定"。
5. **验收门槛会随假设过期。** 「0–2 岁 < 3,000」在 v1 是对的（防假幼儿园），在 v4 会把真实的 2 岁托育判成错误。门槛要跟着口径一起复审；改门槛必须在日志里明写"这是标准修正，不是凑数"，并说清改后少了哪道保险。

## 11.8 v4 新暴露的风险

1. **托育假设整条链没有上海分龄观测支撑**：入托率 0.5%/5%/11%、月费 4,000、早教 15%/25%/18% 都是区间取中值。它同时决定 0–2 的形状**和谷的位置**，是现在最脆弱的一环。
2. **2 岁教育 6,000 已经越过旧门槛 2 倍**：如果真实入托率只有 5%（三岁平均）且集中在 2 岁，教育列还会更高；反之若上海家庭主要靠祖辈照护，6,000 偏高。两个方向都能移动 0–2 的 3,000–4,000 元。
3. **22→23 +14.03% 仍是 Top1**：口径桥的性质没变，只是从"最大跳变"变成"最大且已知的跳变"。若未来要求"全表 |Δ| ≤ 8%"，这一格必须先改口径定义（例如把 22 岁也算青年自身消费），而不是压数。
4. **5→6 +11.12% 被判定为真实台阶**：这个判断依赖"小学阶段支出高于幼儿园"的常识，没有微观账单。若某地实测相反，2b 会立刻把它标红，届时需要重新审 3–5 与 6–11 的篮子，而不是调平滑。
5. **85 岁医疗 14,881.5 仍是"含 4,000 居家照护"的口径**：图里只有 8 类，读图的人看到的是 14,881.5，不是 10,881.5。这条已在 spec §7 与 JSON meta 拆开，但**图表侧仍需标注**（归出图方）。

## 11.9 托育是一个旋钮：入托率三档（E 复核后补，`sensitivity_childcare.json`）

E 复核（`notes/independent/E-v4-recheck.md`）把 v4 的 2→3 **+8.63%** 拆开看：它几乎完全由「2 岁入托率 11%」这一个数决定。三档全链重跑（各自归一化到 54,980、八类锁官方，不是只改教育列）后：

| 档 | 0/1/2 入托率 | 教育 0/1/2 | 2→3 | 谷 | 峰 | 峰谷比 | 30–39 | 40–49 |
|---|---|---|---|---|---|---|---|---|
| `childcare_low`（均值 3%） | 0.3% / 2.5% / 6% | 744 / 2,200 / 3,600 | **+16.44%** | 0 岁 31,444 | 46 岁 64,434.9 | 2.05 | 62,749.6 | 64,273.8 |
| `childcare_mid`（base，5.5%） | 0.5% / 5% / 11% | 840 / 3,400 / 6,000 | **+8.63%** | 0 岁 31,540 | 46 岁 64,414.5 | 2.04 | 62,729.7 | 64,253.4 |

三档的 30–39 / 40–49 均值只差约 **0.06%**，λ 的整体平移 <0.1%——和 glide 的「全表平移 ±1.3%」正好相反：0–2 岁人口权重只有 2.7%，改它不会把整条曲线带着走。**这条参数是局部的，但它是 0–3 段的全部。**

### 教训：一个假设同时改水平、形状和谷位，它就不是参数，是框架选择

- 2 岁 11% → +8.63%；10% → +10.11%；16% → +1.81%；三年平坦各 5% → **+18.13% 且谷回 2 岁**（E 的算例）。所以 2→3 的真实区间约 **+1.8% ~ +18.1%**，"只涨 8.63%"是取 11% 的结果。
- 低档（三岁均值 3%）自己就 **+16.44%，破 12% 红线**。也就是说「0–2 段没有两位数跳变」不是被数据证出来的，是被入托率假设证出来的。**任何引用都必须带上这句**，否则等于把假设当结论卖。
- 基准 11% 是公开区间 5–8%（三岁平均）的**上偏**值，不是点估计。选它是因为 2 岁是托班主体（公办园托班、民办托育多从 2 岁起），不是因为它让检查好看——但两者在结果上无法区分，这是 v4 剩下的最大方法风险（E 的残留问题③）。
- 谷位同理：三档都在 0 岁，是因为 0 岁的用品摊销（6,500）+ 医疗（2,200）压过了教育（744–1,080）；一旦入托率改成三年平坦，谷立刻回 2 岁。**报告"谷在 0 岁"时必须同时报告"它是入托率坡度的函数"。**

### 顺手改的两处

1. **桥的独立红线 15%**：`BRIDGE={18,23}` 原来从 12% 红线里剔除，等于 22→23 +14.03% 永远 FAIL 不了。现在桥单独判 `|Δ| > 15%`，超了 FAIL、不超报余量——当前 **+14.03%，余量 0.97pp**，是全表最贴近红线的一格；17→18 −7.82%，余量 7.18pp。
2. **glide 的说法更正**：v4 初稿写「端点只改 60 岁以后、几乎不反噬壮年段」是错的。三档经 λ 归一后是**全表平移**：30–39 均值 63,583/62,730/61,899（±1.35%），峰（46 岁，在 60 之前）从 65,291 变到 63,561（−2.7%）。对形状成立，对水平不成立——spec §5.3 已改。
